# 💰 BudgetIQ – Smart Expense Tracking & Budget Management System

BudgetIQ is an AI-powered personal finance management web application that helps users track expenses, manage budgets, analyze spending patterns, and receive intelligent financial insights, including the database to store the data..

---

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/ExpenseAI.git
```

Move into project folder:

```bash
cd ExpenseAI
```

Install dependencies:

```bash
cd backend
npm install
```

Start server:

```bash
node server.js
```

Open frontend:

```bash
frontend/index.html
```
